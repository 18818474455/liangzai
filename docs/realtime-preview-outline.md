# 提纲：本机修图怎样把预览做跟手

> 对外可发的拆解提纲。只讲思路和效果，不给实现代码、着色器、模型权重、滑杆默认值、风格配方。

## 标题备选

- 活动摄影桌面修图：我们怎样做本机跟手预览
- 像素不上云的现场修图，预览为什么不能卡

## 要回答的问题

1. 为什么必须本机算，不能把图丢到云上修？
2. 拖滑杆时，怎样避免整帧重算把窗口冻住？
3. 哪些层可以开源（标准 LUT），哪些层必须闭源（引擎 / 模型 / 配方）？

## 结构

### 1. 现场约束

婚礼 / 活动现场可能断网几小时。授权可以短时向服务器要许可，图必须继续在本机算。  
结论：安全不能做成「每张图都上传」。

### 2. 跟手预览的三件事（思路）

- **保旧帧**：新结果没出来之前，屏幕上仍是上一张能看的图，不要闪黑、不要转圈卡死。
- **代理分辨率**：拖动时先算小图，松手再升到成片分辨率。
- **不要堵界面线程**：重活和拖动拆开，丢得掉过期帧。

不写具体分辨率数字、不写着色器、不写网格公式。

### 3. 开源的那一层

标准 Adobe `.cube` 3D LUT、三线性插值、强度混合，已经在 [liangzai-cube-kit](https://github.com/18818474455/liangzai-cube-kit) 开源。  
可以 `npm install`，也可以在 [playground](https://18818474455.github.io/liangzai-cube-kit/) 拖图试。

### 4. 不公开的那一层

修图内核、美颜模型、产品风格 LUT、内部工作空间配方。  
总览与边界：[liangzai](https://github.com/18818474455/liangzai)。

### 5. 结尾同一句

完整软件在官网下载试用。私有化 / 二次开发加微信 `cylbaw`。  
https://www.ybpbyxc.com/download.html
